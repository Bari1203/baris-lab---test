# CHANGELOG — TRADE_MOR

## TM v0.9.0 (16/10/2026)
בסיס: TM v0.8.42 בלי שינוי בלוגיקה. נוסף חלק חדש בהגדרות: **⑧ אזור קריטי ותגובה** (עם מתג ראשי; כבוי = בדיוק v0.8.42).
- **לקיחה:** פנימי קיצוני או חיצוני קיצוני של 1h ומעלה נלקח → סימון ✕ על הגרף + התראה (`TRADE_MOR · לקיחה`), כולל SMT מול ES.
- **תגובה:** אחרי הלקיחה, נר של 5m / 15m / 30m / 1h נסגר חזק בכיוון ההפוך ובחזרה מעבר לרמה, תוך 60 דקות → סימון ▼ / ▲ + התראה (`TRADE_MOR · תגובה`).
- נר חזק: הגוף לפחות 60% מהנר, הפתיל בצד הסגירה עד 15% (הגדרות).
- מנוע הנזילות שולח עכשיו גם את הגבוה/נמוך הפתוח הכי רחוק של כל טיימפריים (בשביל חיצוני קיצוני).
- הסימונים נבנים גם על 24 השעות האחרונות, כך שרואים אותם מיד גם כשהשוק סגור.
